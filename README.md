# Оно тебе надо

Проектная работа первого спринта курса «Фронтенд-разработчик» Яндекс Практикума. Страница аукциона с обложкой, карточками лотов и информацией об аукционе.

Репозиторий: https://github.com/ilyaero1911/ono-tebe-nado-ad

## Просмотр

Откройте `index.html` в браузере. Страница работает без сборки и Live Server. Шрифты, стили и изображения подключены относительными путями.

## Технологии

HTML и CSS: семантические теги, Grid, Flexbox, фоновые изображения, абсолютное позиционирование оверлея. Использована исходная заготовка Практикума. Макет предназначен для страницы шириной 1100 px.
